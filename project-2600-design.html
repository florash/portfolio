Case Study · Brand Website

2600 Design

A studio website for a Canberra web design brand, shaped to feel refined, boutique, and easy to navigate across desktop and mobile.

Visit Live Site More Projects

Overview

Project Goal

2600 Design needed a website that felt credible, refined, and locally relevant rather than generic. The main goal was to present the studio's services and work in a way that felt more polished, more structured, and easier for potential clients to understand quickly.

My Role

What I Did

  • Led the visual direction for the page layout, hierarchy, and overall browsing experience.
  • Developed the page structure and content flow so services and portfolio work felt clearer.
  • Refined typography, spacing, and tone to support a boutique brand feel.
  • Adjusted the responsive layout so the site stayed clean and easy to scan on smaller screens.

Tools

Web Design Responsive Layout HTML / CSS Brand Presentation

Outcome

Result

The final website gives the studio a clearer digital presence with a stronger sense of quality and consistency. It improves how the brand is presented, makes the service offer easier to follow, and creates a more polished first impression for potential clients across desktop and mobile.
